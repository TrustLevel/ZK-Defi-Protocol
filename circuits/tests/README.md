# Circuit Tests

Test suite for the `collateral_proof` ZK circuit.

## Overview

This directory contains:
- **Test scripts** that generate and verify ZK proofs
- **Helper utilities** for commitment calculation
- **Generated artifacts** (auto-created, gitignored)

## Files

### Source Files (Committed)

**`test_v3_circuit.mjs`** - Main test suite
- Runs 4 test scenarios (valid, edge cases, invalid)
- Generates proofs programmatically
- Auto-calculates commitments with Poseidon hash

**`calculate_commitment.js`** - Helper script
- Generates `input_test.json` with correct Poseidon commitment
- Useful for manual testing and debugging

**`README.md`** - This file

### Generated Files (Gitignored)

**`input_test.json`** - Auto-generated by calculate_commitment.js
- Contains test inputs with calculated commitment

**`witness.wtns`** - Circuit witness (binary, ~31KB)
**`proof.json`** - Generated ZK proof (~800 bytes)
**`public.json`** - Public signals from proof

## Quick Start

### Run Full Test Suite

```bash
cd circuits/
npm test
```

Or directly:
```bash
node tests/test_v3_circuit.mjs
```

**Expected output:**
```
✅ Test 1: Valid collateral (150% ratio) - PASS
✅ Test 2: Exact collateral (100% ratio) - PASS
❌ Test 3: Insufficient collateral (50% ratio) - FAIL (expected)
✅ Test 4: High collateral (300% ratio) - PASS

All tests passed!
```

### Manual Testing with calculate_commitment.js

```bash
cd circuits/tests/
node calculate_commitment.js
```

This generates `input_test.json` with a valid Poseidon commitment.

Then generate witness + proof:

```bash
cd ..
node collateral_proof_js/generate_witness.js \
  collateral_proof_js/collateral_proof.wasm \
  tests/input_test.json \
  tests/witness.wtns

npx snarkjs groth16 prove \
  keys/collateral_proof_0000.zkey \
  tests/witness.wtns \
  tests/proof.json \
  tests/public.json

npx snarkjs groth16 verify \
  keys/verification_key.json \
  tests/public.json \
  tests/proof.json
```

**Expected output:** `[INFO] snarkJS: OK!`

## Test Scenarios

The test suite (`test_v3_circuit.mjs`) runs 4 scenarios:

### Test 1: Valid Collateral (150% ratio)
- Collateral: 150 ADA
- Loan: 100 ADA
- Ratio: 150%
- **Result:** ✅ PASS

### Test 2: Exact Collateral (100% ratio)
- Collateral: 100 ADA
- Loan: 100 ADA
- Ratio: 100%
- **Result:** ✅ PASS

### Test 3: Insufficient Collateral (50% ratio)
- Collateral: 50 ADA
- Loan: 100 ADA
- Ratio: 150%
- **Result:** ❌ FAIL (expected - constraint not satisfied)

### Test 4: High Collateral (300% ratio)
- Collateral: 300 ADA
- Loan: 100 ADA
- Ratio: 150%
- **Result:** ✅ PASS

**What each proof demonstrates:**
- ✅ User knows the secret for the commitment
- ✅ Collateral is sufficient for the requested loan
- ❌ WITHOUT revealing the secret or exact collateral amount

## Customizing Tests

### Option A: Edit test_v3_circuit.mjs

Add your own test case:

```javascript
await runTest("Custom test", {
    collateralAmount: 200_000_000, // 200 ADA
    loanAmount: 100_000_000,       // 100 ADA
    collateralRatio: 150
});
```

### Option B: Edit calculate_commitment.js

For manual testing:

```javascript
const collateral_amount = BigInt("1050000000"); // Change this
const secret = BigInt("123456789012345678901234567890"); // Change this
const loan_amount = "700000000"; // Update in output
const collateral_ratio = "150"; // Update if needed
```

Then re-run: `node calculate_commitment.js`
