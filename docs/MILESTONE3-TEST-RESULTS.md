### Aiken on-chain tests (`contracts/lib/zk_onchain_test.ak`)

Both tests call `zk.verify_collateral_proof` — the exact helper the v5 validators use —
with a **real BLS12-381 Groth16 proof fixture** generated by
`circuits/tests/gen-onchain-fixture.cjs`.

| Test | Assertion | Status | ExUnits (mem / cpu) |
|---|---|---|---|
| `collateral_proof_verifies_onchain` | valid proof → `true` | pass | 42,467 / 2,268,410,848 |
| `tampered_public_signal_fails_onchain` | flip `loan_amount` public signal → `false` | pass | 43,068 / 2,268,582,897 |

### Off-chain proof gate (`circuits/tests/gate-bls12381.cjs`) — 9 checks

1. groth16 verify == true (valid case)
2. exactly 3 public signals
3. publicSignals[0] == commitment
4. publicSignals[1] == loan_amount
5. publicSignals[2] == collateral_ratio
6. vkey curve == bls12381
7. poseidon255 deterministic (same inputs → same commitment)
8. tampered public signal → verify == false
9. insufficient collateral → proof generation **rejected** (witness fails constraint 2)

## 2. Edge cases demonstrated

| Edge case | Where | Expected | Observed |
|---|---|---|---|
| **Tampered public signal** (verifier fed wrong `loan_amount`) | off-chain gate #8 **and** on-chain `tampered_public_signal_fails_onchain` | proof rejected | verify == false (both off-chain and **on-chain**) |
| **Insufficient collateral** (10 ADA collateral, 10 ADA loan @125% → 1e9 < 1.25e9) | off-chain gate #9 | proof cannot be generated | `snarkjs fullProve` errors at circuit constraint `ge.out === 1` (template `ProveOwnership` line 81) — no valid witness exists |
| **On-chain public-signal binding** | `lending_pool_v5.ak` | redeemer signals can't be forged | `commitment` read from referenced collateral UTxO; amounts cross-checked vs. pool value delta / `total_borrowed`; ratio from pool datum |
| **VKey immutability** | `zk.ak get_vkey` + always-false park | key cannot be swapped | VKey parked at unspendable address, only ever read as reference input |
| **Unlock with equality constraint** | `collateral_v5.ak` (`unlock_ratio = 100`) | ownership-only proof | `collateral*100 >= collateral*100` holds with equality; live unlock confirmed |

**Note on proof-tx fees:** the borrow/repay/unlock fees above were produced with a
deliberately over-budgeted ExUnit setting (mem 14M / steps 10B) because Blockfrost
auto-evaluation returns opaque failures for these heavy BLS12-381 scripts. Since the
Cardano fee is priced on *budgeted* ExUnits, these fees are an upper bound. The
isolated verification cost is only ~43k mem / ~2.27B cpu, so the off-chain scripts have
since been tightened to **mem 900k / steps 4B** (`offchain/cli/v5/{4-borrow,5-repay}.mjs`),
which will materially lower the proof-tx fee on the next cycle while keeping ample
headroom. (The tightened budget is a code change; re-confirming the reduced fee
requires a fresh live cycle and was not re-run to avoid disturbing the confirmed
evidence above.)

## 5. Tester feedback

Internal review (Dominik Tilman, solo maintainer):

- The isolated on-chain `groth_verify` test was treated as the make-or-break gate;
  passing it validated the architecture before any tx-flow work — feasibility risk
  retired early.
- The historical "redeemer CBOR" theory was adversarially falsified with an offline
  CBOR diagnosis before rebuild; the real root cause (`ScriptContext` vs `Transaction`
  as the 4th spend arg) was found by diffing against two known-working reference repos.
- Blockfrost auto-evaluation of BLS12-381-heavy scripts is unreliable (opaque
  `ScriptFailures`); manual ExUnit budgeting was required — noted as a tooling
  limitation, not a protocol issue.
